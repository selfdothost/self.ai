# Contributing

self.ai is GPL-3.0 and welcomes contributions.

!!! note "Guidelines coming soon"
    This page is a placeholder. Detailed contribution guidelines — code style, the PR
    process, and how `DIVERGENCE.md`'s no-upstream-ingestion rule affects patches — are
    not written up yet.

In the meantime: open an issue on
[GitHub](https://github.com/selfdothost/self.ai/issues) to discuss a change before
sending a large patch, and see
[DIVERGENCE.md](https://github.com/selfdothost/self.ai/blob/main/DIVERGENCE.md) for the
fork's provenance and the licensing posture that follows from it, which any contribution
needs to respect.
